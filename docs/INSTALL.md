# 安装指南

## 不需要管理员权限

汉化**完全不需要**以管理员身份运行 IDEA，也**不需要**修改 `Program Files` 安装目录。  
IDEA 2024.2+ 已**内置**官方中文语言包，只需启用并切换语言即可。

---

## 最常见原因：官方中文包被禁用了

如果你按之前的说明**禁用了官方「Chinese (Simplified) Language Pack」**，同时社区语言包尚未被 IDE 正确识别，就会出现：

- 「语言与区域」里已选 **简体中文**
- 但界面**仍然是英文**

这是因为 IDE 找不到任何有效的 `zh-CN` 翻译资源。

### 一键修复（无需管理员）

在项目目录运行：

```powershell
.\scripts\fix-locale.ps1
```

然后：

1. **完全退出** IDEA（不是 Reload Window）
2. 重新打开 IDEA
3. `Ctrl+Alt+S` → **插件** → **已安装**
4. **启用** `Chinese (Simplified) Language Pack / 中文语言包`（JetBrains 官方）
5. **禁用** `IntelliJ IDEA 社区中文语言包`（暂时不用社区版）
6. 确认 **外观与行为 → 系统设置 → 语言与区域 → 语言 = 简体中文**
7. **再次完全重启** IDEA

重启后 `File` 应变为 **文件**。

## 推荐方案（官方内置，最稳定）

| 步骤 | 操作 |
|------|------|
| 1 | 打开 IDEA（普通用户身份即可） |
| 2 | `Ctrl+Alt+S` → **插件** → 确认官方 **中文语言包** 已**启用** |
| 3 | `Ctrl+Alt+S` → **外观与行为 → 系统设置 → 语言与区域** |
| 4 | **语言** 选择 **简体中文** |
| 5 | 完全重启 IDEA |

> 参考：[JetBrains 官方文档 - 语言和区域](https://www.jetbrains.com/zh-cn/help/idea/language-and-region.html)

## 常见问题

### Q: 需要管理员权限吗？

**不需要。** 插件安装在 `%APPDATA%\JetBrains\` 下，普通用户即可。

### Q: 语言选了简体中文但还是英文？

99% 是官方中文包 `com.intellij.zh` 被禁用了。运行 `fix-locale.ps1` 并按上文重新启用。

### Q: Reload Window 够吗？

不够，必须**完全退出 IDEA 再打开**。
