# 安装指南

安装语言包插件后界面仍是英文，**99% 是因为没有手动切换 IDE 语言**。从 IDEA 2024.2 起，安装语言包 ≠ 自动变中文。

## 正确安装步骤（请严格按顺序）

### 第 1 步：安装社区语言包

1. 下载 [releases/com.chinese.idea.localization-1.0.3.jar](https://github.com/Ms-liyc/IDEA-Chinese/blob/main/releases/com.chinese.idea.localization-1.0.3.jar)
2. 打开 IDEA → `Ctrl+Alt+S` → **插件**
3. 点击 ⚙ → **从磁盘安装插件…** → 选择 JAR
4. 确认插件 **IntelliJ IDEA 社区中文语言包** 已**启用**（勾选）

### 第 2 步：禁用官方中文语言包（重要）

仍在 **插件 → 已安装** 中：

1. 找到 **Chinese (Simplified) Language Pack / 中文语言包**（JetBrains 官方）
2. 点击 **禁用**
3. 两个中文语言包同时启用会冲突，必须只保留社区版

### 第 3 步：切换 IDE 语言（最关键）

1. `Ctrl+Alt+S` 打开设置
2. 进入 **外观与行为 → 系统设置 → 语言与区域**
3. **语言** 下拉框选择 **简体中文**（或 Chinese (Simplified) 简体中文（社区版））
4. 点击 **确定**，按提示**完整重启 IDE**

> 仅 Reload Window 无效，必须完全退出 IDEA 再重新打开。

### 第 4 步：验证

重启后检查：

- 菜单 **File** 应变为 **文件**
- 设置 **Settings** 应变为 **设置**
- 插件列表中社区语言包为**已启用**

## 常见问题

### Q: 语言下拉框里没有「简体中文」？

- 确认社区语言包插件已**启用**（不是仅安装）
- 确认未被 IDEA 版本限制拦截（需 IDEA 2024.2+）
- 尝试先禁用再重新启用插件，然后重启

### Q: 选了简体中文但部分仍是英文？

- 正常现象：新版 AI 功能、部分插件词条可能尚未翻译
- 运行 `python scripts/l10n.py report --output` 查看缺口

### Q: 官方语言包禁用后想用回官方？

- 重新启用 **Chinese (Simplified) Language Pack**
- 禁用社区语言包
- 在「语言与区域」重新选择简体中文并重启

### Q: 能否不禁用官方包？

- 不建议。两个 `zh-CN` 语言包同时启用时，IDE 可能只加载其中一个或表现异常
